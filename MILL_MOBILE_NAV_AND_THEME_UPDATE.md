# Mill Hub mobile navigation and theme update

Based on the latest uploaded main.zip.

- Mobile bottom navigation now shows four primary tabs plus More.
- More opens a scrollable drawer containing all permitted Mill Hub modules.
- Selecting a More item navigates to it and closes the drawer.
- Added persistent Light/Dark theme toggle to mobile header and desktop Mill sidebar.
- Dark palette and dark input/card overrides retain the Mills indigo/teal identity.
- Increased mobile content bottom padding and retained safe-area support.
- Existing API actions, permissions, forms, calculations and backend integrations preserved.

Validation: generated inline JavaScript checked with node --check. Full Expo build and live
iOS/Android device QA remain to be run in the user's environment.
