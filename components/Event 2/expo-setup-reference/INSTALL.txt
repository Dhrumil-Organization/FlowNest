EXPO DEPENDENCY INSTALL — run these from your project root
============================================================

Always install Expo SDK packages with `npx expo install` (NOT plain npm install).
`expo install` automatically picks the versions that match YOUR installed Expo SDK,
so you never end up with a native module that's incompatible with your runtime.

1) Native / Expo modules used by this feature
----------------------------------------------
npx expo install expo-sqlite expo-network expo-image-picker @expo/vector-icons @react-native-async-storage/async-storage @react-native-picker/picker

2) Navigation (only if not already installed)
----------------------------------------------
npx expo install @react-navigation/native react-native-screens react-native-safe-area-context

3) Plain JS libraries (regular npm)
----------------------------------------------
npm install axios
npm install --save-dev babel-plugin-module-resolver

4) REMOVE the old bare-React-Native packages (they are replaced)
----------------------------------------------
npm uninstall react-native-sqlite-storage @react-native-community/netinfo react-native-image-picker react-native-vector-icons

  Replacement map:
    react-native-sqlite-storage      ->  expo-sqlite
    @react-native-community/netinfo  ->  expo-network
    react-native-image-picker        ->  expo-image-picker
    react-native-vector-icons        ->  @expo/vector-icons

After changing any native dependency or app.json plugins, rebuild the dev client:
    npx expo prebuild --clean        # only if you use a custom/dev build
    npx expo run:android             # or: npx expo run:ios
If you are on Expo Go, just restart with cache cleared:
    npx expo start -c
